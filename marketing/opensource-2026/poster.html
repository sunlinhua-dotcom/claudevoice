ClaudeVoice

is now open source.

正式开源

每个 Claude Code 会话跑完、卡住、等你授权，它都会开口告诉你：是哪个项目，发生了什么。

语音播报

任务完成、等输入、要授权都会念出来，附一句中文摘要；默认免费 TTS，无需 API key。Spoken alerts with an AI summary

手机推送

网页指挥台加 Web Push，装成 PWA，人离开电脑也能在手机上收到提醒。Web panel + phone push

飞书远程驱动

在飞书私聊里指挥 Claude Code：审批卡片、多会话切换、发语音下指令。Drive Claude Code from Feishu

Mac 菜单栏 App

本机播报、语音听写、把文字直接注入正在用的输入框。Native macOS menu-bar app

项目专属提示音

给每个项目生成一段自己的音效，不用看屏幕，一听就知道是谁。A unique sound per project

微信 brief 归档

客户在微信发来的需求，自动归档进对应项目的文件夹。WeChat briefs, auto-filed

Cloudflare 或自托管

可以部署成 Worker 加 Durable Object 的边缘服务，也可以只在本机运行。Edge or fully self-hosted

硬件小盒子同步念

可选接入 ESP32 小智盒子，桌上的设备和电脑同步播报。Optional ESP32 voice box
